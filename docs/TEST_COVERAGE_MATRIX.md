SHA values in the matrix are the first 12 characters of the full commit SHA. “Last verified” means the latest inspected passing execution for the mapped behavior; it does not imply that every listed test ran on the snapshot SHA.

| Status | Meaning |
|---|---|
| `VERIFIED` | The mapped test or check ran and passed at the recorded SHA. |
| `COVERED BUT NOT RUN` | A relevant test exists, but it was not executed in the current verification event. |
| `MISSING` | Source and tests were inspected; no adequate test was found for this requirement. |
| `BLOCKED` | A required check could not be run because a dependency or permission was unavailable. |
| `NOT APPLICABLE` | The behavior is outside the implemented product scope. |

Requirement coverage, route/role coverage, test execution, Java line/branch coverage, and browser coverage are tracked separately below. No percentages are calculated because the complete requirement denominator and Java coverage instrumentation are not defined.
